# Learning Loop

The learning loop turns evidence about its own operation into durable knowledge and applies that knowledge with increasing system ownership.

## Language

**Rule**:
An operator-promoted obligation that states what must remain true and why it is authoritative. An I2 Rule is delivered for agent judgment; an I3 Rule is enforced at an action boundary.
_Avoid_: Invariant, policy

**Enforcement**:
A deterministic mechanism that guarantees a rule's required effect at a specified action boundary. Delivery to an agent is not enforcement.
_Avoid_: Agent enforcement, advisory enforcement

**Internalization Level**:
The degree to which the learning loop owns the timely application of knowledge: **I1 Discoverable** requires agent retrieval and judgment; **I2 Delivered** guarantees timely presentation but retains agent judgment; **I3 Enforced** guarantees deterministic application at an action boundary.
_Avoid_: State-1, state-2, state-3; L1, L2, L3
